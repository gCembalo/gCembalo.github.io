Here there is my collection of template that I used for my Academic journey.

LaTeX Template

This repository contains a basic/medium template used take and publish notes of lectures of the theoretical physics degree at University of Turin. It is organized like a book and designed for a full course. Most of the notes I've written using this template are around 300 pages long. Its only purpose is to provide an appealing layout, but if you add the Thesis cover Template it can easly became a complete thesis template.

Academic CV Template

This is a basic academic CV written during my MSc in theoretical physics seen the necessity to apply to some Summer School. This template, as you can easly verify, it's inspired by Dubasi Pavan Kumar's template, that you can find here on Overleaf, simply searching his name.

Beamer Template

This is a basic beamer document, which is based on a presentation I gave during GraSPA2026 Summer School, but it can be easly used for a BSc or MSc thesis defence.

Thesis cover Template

This is a title page written during my BSc in physics thesis project.

Academic Transcript Template

This is a basic Academic Transcription written during my MSc in theoretical physics seen the necessity to apply to some Summer School.

Motivation Letter

This is a basic academic Motivation Letter written during my MSc in theoretical physics seen the necessity to apply to some Summer School. This template, as you can easly verify, it's inspired by Zheng-hu Nie and Fanchao Chen's template. You can find their template on ths link.
